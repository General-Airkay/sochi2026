# sochi2026

AI Prompt

Design a luxury, elegant, premium multi-page wedding website inspired entirely by the attached wedding invitation for SoChi2026. The design must closely match the invitation's visual identity, colours, typography, floral decorations and premium wedding aesthetics.

The website should feel timeless, romantic, royal and sophisticated, with subtle gold animations, soft floating particles, elegant transitions and premium micro-interactions.
